## 요약

- **rule 만 "유지" 기준을 통과했다.** 정확도 유지율 99.8% [99.0, 100.5], Holm 보정 McNemar p = 1.0 이다 (잠정).
- **LLMLingua-2 세 조건은 모두 "손실"이다.** dev 에서는 유의하지 않았던 손실이 test(n=139)에서 분명하게 나왔다.
  - r50: 유지율 92.0% [87.8, 95.7], 보정 p = 0.0002 (잠정)
  - rule>llmlingua2: 유지율 89.4% [84.5, 94.1], 보정 p < 0.0001 (잠정)
  - r30: 유지율 75.1% [68.0, 81.8], 보정 p < 0.0001 (잠정)
- **손실은 fact 와 multi 에 몰린다.** code 는 LLMLingua-2 의 모든 조건에서 0.976~1.000 이다 (fenced code block 보호). fact 는 r30 에서 0.447 이다.
- **중복성이 근거 삭제를 버티게 한다는 dev 결과를 재현했다.** drop_evidence 에서 중복도 1 의 정확도는 0.103, 2+ 는 0.606 이다 (Fisher p < 0.001).
- **closed-book 부분집합에서도 유지율이 거의 같다.** 문서 없이 못 맞히는 50문항(S_A)에서 r50 93.1%, r30 76.0%, rule>llmlingua2 86.8% 다. 전체 유지율이 모델 지식으로 부풀지는 않았다.

- **empty:** 정확도 0.000, NOT FOUND 100% (139/139). dev 와 같다. 맞힌 문항(accuracy ≥ 0.5)은 없다.
