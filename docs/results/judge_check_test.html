라벨 기준 (labeling_guide.md 1절)

모델 답변이 이 핵심 사실을 의미상 전달했으면 O, 아니면 X.

  • 표현이 달라도 의미가 같으면 O
  • 관련 단어만 있고 사실을 말하지 않으면 X
  • 사실과 모순되면 X
  • 답변의 다른 부분이 틀렸더라도 이 핵심 사실을 전달했으면 O (사실 하나씩 본다)
  • 사실을 말하면서 "문서에 없다"는 말을 덧붙여도, 사실을 전달했으면 O
  • 한 행씩 독립으로 본다. 판단이 어려우면 가장 가까운 값을 넣고 메모에 이유를 쓴다

judge 판정은 이 화면에 없다 (블라인드). 단축키: O / X 라벨 후 다음 행, J/K 다음/이전, M 메모 칸. 입력은 이 브라우저에 자동 저장된다. 끝나면 CSV 내려받기로 받은 파일로 docs/results/judge_check_test.csv 를 바꾼다.
