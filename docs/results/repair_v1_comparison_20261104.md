## 설정 차이 — 효과 귀속의 제한

기록상 답변 모델 gpt-6-luna, judge deepseek-flash, embed bge-m3, seed 42, reasoning_effort none, 답변/채점 프롬프트 해시는 같다. 그러나 **답변 temperature는 기존 0.0, repair null(미지정)**이다. 제공자 기본값이 실제 어떤 동작을 했는지는 이 로그로 확정할 수 없다. repair 실행에서 기존 r30/r50을 동시에 다시 평가하지도 않았다.

따라서 r30의 큰 차이는 유망한 관측 결과이나 복원 기법의 순수 인과 효과로 확정하지 않는다. 입력 토큰 증가도 효과의 일부로 함께 보고한다. 온도·시간·생성/채점 변동을 분리하려면 같은 설정으로 기존/repair를 비교해야 한다.

기반 압축문 토큰 수는 기록이 존재하는 경우 기존과 대부분 일치한다(r50 129건, r30 133건). 정렬 실패로 base_context_tokens가 없는 건도 있어 불일치 수를 모두 실제 기반 압축 변경으로 해석하지 않는다. 토큰 수 일치만으로 문맥 문자열 일치가 증명되는 것도 아니다.
