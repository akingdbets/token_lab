# DuckDB 멀티턴 v2 데이터셋

DuckDB 영어 OpenWiki에 근거한 멀티턴 평가 데이터셋 초안이다. 시나리오 20개, 각 19턴으로 총 380턴이며 모두 `draft` 상태다. 사람 검수와 모델 평가는 아직 실행하지 않았다.

원문 코퍼스는 [PR #64](https://github.com/akingdbets/token_lab/pull/64)의 `data/openwiki/duckdb-en`이다. 기준 head는 `eda7e1a19d4189785b81c4a0e2baf27aa8b18689`이며, 새 환경에서 사용하려면 해당 코퍼스가 필요하다.

Kafka 멀티턴 v2와 같은 스키마를 사용한다. 각 시나리오는 문서 8페이지를 한 번씩 첨부하고, 전체에서 본문 54페이지를 포함한다. 질문·참고 정답·채점 사실·근거 인용·턴 의존 관계를 각 JSON에 담았다. 프로젝트 고유 값의 변경과 이후 회상을 포함한다.

Python 클라이언트, CSV·JSON·Parquet, 다중 데이터베이스, Secrets, CLI, 성능, SQL 및 유지보수 주제를 다룬다. 폴더 최상위 JSON 20개는 기존 `load_scenarios`로 읽을 수 있다.

현재 Codex 세션에서 문서 사실과 질문을 작성하고 공통 19턴 배치로 조립했다. 질문 구조와 연결·메타데이터 문항이 반복되므로 20개를 완전히 독립적인 표본으로 해석하지 않는다. 문서 예시보다 기본 동작을 묻는 비중이 높아 난이도와 대화의 자연스러움은 후속 검수 대상이다.
