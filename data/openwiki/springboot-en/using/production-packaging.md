# Packaging Your Application for Production

Once your Spring Boot application is ready for production deployment, there are many options for packaging and optimizing the application. See the [packaging/index.adoc](https://docs.spring.io/spring-boot/4.2.0/reference/packaging/index.html) section of the documentation to read about these features.

For additional "production ready" features, such as health, auditing, and metric REST or JMX end-points, consider adding `spring-boot-actuator`. See [actuator.adoc](https://docs.spring.io/spring-boot/4.2.0/how-to/actuator.html) for details.
