# OpenWiki Instructions

Write every wiki page in English.
The readers of this wiki are developers who use FastAPI, from beginners to advanced users.
Prioritize usage over internal implementation. Cover every topic of the user documentation
(docs/en/docs) as pages: request body, path and query parameters, response models,
dependency injection, security and authentication, middleware and CORS, databases,
background tasks, testing, and deployment.
Each page must include example code (from docs_src) and exact class, function and parameter names.
Cover the library internals only as far as users need them.
