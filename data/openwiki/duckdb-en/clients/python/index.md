# Files

- [Python Data Ingestion and Conversion: pandas, Arrow, Polars and NumPy](dataframes-and-arrow.md) - How the DuckDB Python client reads CSV/Parquet/JSON files, queries pandas, Polars, NumPy and Arrow objects by variable name (replacement scans), registers objects, converts results with df(), fetchnumpy(), to_arrow_table(), pl() and friends, and maps Python objects to DuckDB types.
- [Python Expression API, UDFs, Types and Appender](expressions-udfs-and-types.md) - Build relational filters and computed columns with col(), lit(), when(), fn() and friends; register Python UDFs with create_function (native or Arrow, NULL and exception handling, side effects); describe SQL types with DuckDBPyType; and bulk-insert, upsert, update or delete rows with the Python appender.
- [Python Client: Installation, Connections, DB-API and Threads](getting-started.md) - Install the duckdb Python package (2.0.1, Python 3.11+), run SQL with duckdb.sql and connections, use the DB-API (execute, fetch, parameters, transactions, open results), share work across threads with cursor(), use Jupyter/JupySQL, and migrate Python code from DuckDB 1.x to 2.0.
- [Python Integrations: Spark API, Ibis, PyTorch, marimo and fsspec](integrations.md) - Use DuckDB from other Python ecosystems — the experimental PySpark-compatible API, Ibis (which needs DuckDB below 2.0), streaming query results into PyTorch tensors, reactive SQL cells in marimo notebooks, and querying fsspec filesystems with register_filesystem.
- [Python Relational API](relational-api.md) - Build DuckDB queries step by step with DuckDBPyRelation — lazy evaluation and materialize(), relation creation (sql, table, read_csv, from_df, values), inspection (columns, types, explain, sql_query), transformations (filter, select, aggregate, group_by, join, union_by_name, pivot, with_columns), aggregate/window function methods, and output methods (df, to_arrow_table, iter_rows, create, insert_into, write_csv, write_parquet).
