# OpenWiki Instructions

Write every wiki page in English.
The readers of this wiki are developers and data analysts who use DuckDB, from beginners to advanced users.
Prioritize usage over internal implementation. Cover every topic of the user documentation
(docs/2.0) as pages: connecting and configuration, the SQL dialect and its DuckDB-specific syntax,
query syntax, statements, data types, functions (text, list, struct, date/time, aggregate, window),
importing and exporting data (CSV, JSON, Parquet, multiple files, partitioning), the Python client
and its relational API, the CLI client, performance tuning, and troubleshooting.
Each page must include example SQL or code (from the documentation) and exact statement, function,
option and parameter names. Keep the exact default values and version notes that the documentation states.
Cover internals only as far as users need them.
