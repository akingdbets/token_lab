# Files

- [COPY and EXPORT/IMPORT DATABASE](copy-and-export.md) - The DuckDB COPY statement — COPY ... FROM to append file data into a table, COPY ... TO to write tables or query results to CSV, Parquet, JSON or BLOB files, general and format-specific options with defaults (ORDER_BY, PARTITION_PATH, RETURN_COLUMN_TYPES and Parquet timestamp options new in 2.0), COPY in CTEs (new in 2.0), COPY FROM DATABASE, and EXPORT/IMPORT DATABASE.
- [CREATE TABLE, Constraints, ALTER TABLE, DROP, Schemas and Sequences](create-and-alter-tables.md) - Defining and evolving DuckDB schema objects — CREATE TABLE with OR REPLACE, IF NOT EXISTS, temporary tables, CTAS and schema copies, generated columns; CHECK, NOT NULL, PRIMARY KEY, UNIQUE (DEFERRED, new in 2.0) and FOREIGN KEY constraints; ALTER TABLE operations and their limitations on indexed tables; DROP with RESTRICT/CASCADE; CREATE SCHEMA with nested schemas (new in 2.0); CREATE SEQUENCE, nextval, currval and setval (new in 2.0).
- [DESCRIBE, SHOW, SUMMARIZE, EXPLAIN/Profiling, CALL and Metadata Functions](inspection-and-metadata.md) - Inspecting DuckDB schemas and queries — DESCRIBE and SUMMARIZE for tables and queries, SHOW for settings (new in 2.0; SHOW for tables deprecated) plus SHOW DATABASES / SCHEMAS / VARIABLES / EXTERNAL RESOURCES, EXPLAIN, EXPLAIN (SQL) (new in 2.0) and EXPLAIN ANALYZE, CALL, the duckdb_* metadata table functions and views, and information_schema with catalog functions.
- [INSERT, UPDATE, DELETE, MERGE INTO and the Appender](modifying-data.md) - Modifying data in DuckDB — INSERT with VALUES or queries, BY POSITION / BY NAME, ON CONFLICT DO NOTHING / DO UPDATE (upsert) with EXCLUDED and conflict targets, INSERT OR IGNORE / OR REPLACE, RETURNING; UPDATE with FROM and joins; DELETE, USING and TRUNCATE; MERGE INTO with WHEN MATCHED / NOT MATCHED [BY SOURCE|TARGET] and merge_action, including an SCD Type 2 pattern; and bulk loading with the Appender.
- [PIVOT and UNPIVOT](pivot-and-unpivot.md) - DuckDB's PIVOT (PIVOT_WIDER) and UNPIVOT (PIVOT_LONGER) statements — the simplified syntax with ON, USING, GROUP BY and IN filters, dynamic column detection, multiple ON/USING/GROUP BY expressions and generated column names, pivots in CTEs and subqueries, expressions in USING, the SQL-standard PIVOT (... FOR ... IN ...) and UNPIVOT [INCLUDE NULLS] forms, COLUMNS-based dynamic unpivoting and unpivoting into multiple value columns.
- [Transactions, CHECKPOINT, VACUUM, ANALYZE and Reclaiming Space](transactions-and-maintenance.md) - DuckDB transaction statements (BEGIN TRANSACTION, COMMIT, ROLLBACK/ABORT), auto-commit behavior of multi-statement batches, snapshot isolation; CHECKPOINT and FORCE CHECKPOINT including in-memory checkpointing; VACUUM's limited semantics and index-aware vacuuming (new in 2.0); ANALYZE for join-order statistics; and how to reclaim disk space after deletes.
- [Views, Macros, Custom Types, Triggers and Comments](views-macros-and-types.md) - DuckDB catalog objects beyond tables — CREATE VIEW and SECURE VIEW (new in 2.0), ALTER VIEW; CREATE MACRO / CREATE FUNCTION with scalar and table macros, typed and default parameters, named arguments, overloading, expansion and limitations; sharing macros through attached database files; CREATE TYPE for ENUM, STRUCT, UNION and aliases; CREATE TRIGGER (new in 2.0) with row and statement granularity, transition tables and limitations; COMMENT ON.
