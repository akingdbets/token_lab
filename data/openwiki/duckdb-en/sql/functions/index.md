# Files

- [Aggregate Functions](aggregate.md) - DuckDB aggregate functions and their modifiers — DISTINCT, ORDER BY inside aggregates, FILTER, NULL handling and empty groups; general aggregates (arg_max/arg_min, count, list, string_agg, histogram, lttb new in 2.0, decimal_average new in 2.0, top-N min/max), approximate aggregates, statistical aggregates (quantiles, regression), ordered-set WITHIN GROUP aggregates, and grouping().
- [Date, Time, Interval, Date Part and Date Format Functions](date-and-time.md) - Functions and operators for DATE, TIME and INTERVAL values — date arithmetic, date_add/date_diff/date_sub/date_trunc, time_bucket, make_date, last_day, dayname, the date part specifiers and their synonyms for date_part/extract, interval constructors (to_days, to_months, ...), and strftime/strptime/try_strptime format specifiers including CSV dateformat options.
- [List, Array and Lambda Functions](list-array-and-lambda.md) - Functions for DuckDB LIST and ARRAY values — indexing and slicing rules, list operators (&&, @>, <@, ||, <=>, <->), common list_* functions and their array_* aliases, list comprehensions, range and generate_series, list_aggregate and list_* rewrites, list_sort ordering, flatten, ARRAY distance/similarity functions, and lambda functions (list_transform, list_filter, list_reduce, index parameters, scoping, the deprecated -> syntax).
- [Function Basics, Numeric and Utility Functions](overview-numeric-and-utility.md) - How to call DuckDB functions (dot-operator chaining, listing functions with duckdb_functions()), numeric operators including / vs // and division-by-zero behavior, the ! factorial precedence change in 2.0, numeric functions (round, round_even, trunc, log, gcd, random, decimal_division new in 2.0), and utility scalar and table functions (coalesce, nullif, typeof, hash, uuid, current_setting, query, query_table, glob, repeat_row, sql_tokenize).
- [Struct, Map, Union, Enum and Nested Functions](struct-map-and-union.md) - Functions for DuckDB STRUCT and TUPLE values (struct_pack, row, struct_extract, struct_extract_at, struct_insert, struct_update, struct_concat, struct_keys/values, remap_struct), MAP values (map_extract vs map_extract_value, map_entries, map_from_entries, map_concat, switch), UNION values (union_value, union_extract, union_tag) and ENUM types (enum_range, enum_code), plus a map of nested-type function pages.
- [Text Functions, Pattern Matching and Regular Expressions](text-and-pattern-matching.md) - DuckDB string functions and operators (slicing, concat vs ||, substring, split_part, string_split, trim, lpad, replace, translate, parse_path, grapheme functions, overlay new in 2.0), text similarity (levenshtein, jaro_winkler), format() and printf() formatters, LIKE/ILIKE with ESCAPE, SIMILAR TO, GLOB, the ~ operators (partial match since 2.0), and RE2 regexp_* functions with options and capture groups.
- [TIMESTAMP and TIMESTAMPTZ Functions](timestamp.md) - Functions and operators for TIMESTAMP and TIMESTAMP WITH TIME ZONE — arithmetic, age/ago, date_diff vs date_sub, date_trunc, struct date_part, epoch/epoch_ms/epoch_us/epoch_ns, make_timestamp variants, strptime with format lists, time_bucket, range/generate_series, current_timestamp/now, ICU time-zone-aware functions, timezone() and AT TIME ZONE, string casts with offsets, calendars and DST behavior.
- [Window Functions and the WINDOW Clause](window.md) - DuckDB window functions — OVER with PARTITION BY and ORDER BY, general-purpose window functions (row_number, rank, dense_rank, lag, lead, first_value, nth_value, ntile, fill), aggregates as window functions with DISTINCT and ORDER BY arguments, IGNORE/RESPECT NULLS, frames (ROWS, RANGE, GROUPS) and their defaults, EXCLUDE, named windows with the WINDOW clause, and filtering with QUALIFY.
