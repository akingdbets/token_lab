# Files

- [Extensions: INSTALL, LOAD, Updates and External Resources](extensions.md) - How to install and load DuckDB extensions (INSTALL, LOAD, the new INSTALL AND LOAD), install from the community or custom repositories, keep them current with UPDATE EXTENSIONS, rely on backup extension repositories, manage external resources (CREATE/REGISTER/DESTROY EXTERNAL RESOURCE, new in 2.0), and use the fts full-text search extension.
- [Secrets Manager and CREATE SECRET](secrets-manager.md) - Manage credentials for S3, GCS, R2, Azure, HTTP, Hugging Face, PostgreSQL, MySQL and other services with DuckDB's Secrets Manager — secret types and providers (CONFIG, credential_chain), temporary, persistent and connection-scoped secrets (new in 2.0), scopes and which_secret, listing with duckdb_secrets() and deleting with DROP SECRET.
- [Configuration Options, SET and PRAGMA](settings-and-pragmas.md) - Configure DuckDB with SET, RESET and scopes (GLOBAL, SESSION), inspect settings with current_setting() and duckdb_settings(), the most important options with their defaults (memory_limit, threads, temp_directory, preserve_insertion_order, enable_external_access, ...), PRAGMA statements for metadata, profiling and checkpointing, and SQL variables with SET VARIABLE and the $name shorthand (new in 2.0).
